# Redux Cart and Counter

React Redux practice with counter and cart components, action and reducer files, and a central store.

## Project structure

- `src/components/Cart.jsx`
- `src/components/Counter.jsx`
- `src/redux/countAction.js`
- `src/redux/countReducer.js`
- `src/redux/store.js`

## Getting started

Install Node.js and npm, then run:

```bash
git clone https://github.com/JAYANTI-THAKOR-941/redux-app-2.git
cd redux-app-2
npm install
npm run dev
```

Open the development URL displayed in the terminal.
